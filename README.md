# منصة Mr. Hamada Ramadan — المشروع الكامل

هذه هي **النسخة الكاملة والنهائية** من المشروع بكل التعديلات اللي عملناها
مع بعض من أول يوم لحد دلوقتي، مجمّعة في مكان واحد ومُختبرة بالكامل.

## 🧹 تم حذف كل الصفحات القديمة غير المستخدمة
بعد ما استبدلنا الصفحة الرئيسية بتصميم Stitch الجديد (اللي بقى فيه كل حاجة
—الهيدر، القسم الترحيبي، اختيار المرحلة، الفوتر — في ملف واحد متكامل)،
الصفحات القديمة اللي كانت بتتجمع مع بعض لتكوين الصفحة الرئيسية القديمة
بقت مالهاش أي استخدام خالص. اتحذفوا نهائيًا من المشروع ومن الروابط:
- `All of them.html` (الصفحة الرئيسية القديمة)
- `header - Copy - Copy.html`
- `section 2 - Copy - Copy - Copy - Copy - Copy.html`
- `Second section.html`
- `Section Three - Copy - Copy.html`
- `Footer.html`

اتأكدت إن حذفهم مأثرش على أي حاجة تانية في الموقع (اختبرت كل صفحة نشطة
لسه شغالة، والروابط القديمة بقت بترجع 404 نضيفة بدل ما تكسر الموقع).

## ⚠️ اقرأ الجزء ده الأول — بصراحة تامة

### الملفات الثنائية (صور/خطوط/الوسائط) — **مش موجودة هنا**
معنديش نسخة من:
- `Frontend/static/images/` و `Frontend/static/Fonts/` (الصور والخطوط الفعلية)
- `media/` (صور الكورسات والطلاب المرفوعة)

دول ملفات ثنائية اترفعتليش أبدًا في أي مرحلة من المحادثة، فمستحيل أضيفهم.
**لازم تنسخهم يدويًا** من مشروعك الحالي الشغال إلى نفس المكان في المشروع
ده قبل ما تشغّله، وإلا الصور مش هتظهر والخطوط هترجع للخط الافتراضي.

### كل حاجة تانية (كود + قوالب + تصميمات) — **موجودة بالكامل هنا**
كل ملفات Python والـ HTML/CSS اللي اتكلمنا عليها مع بعض موجودة، **مُختبرة
فعليًا** من خلال Django حقيقي (مش بس كتابة كود) قبل التجميع النهائي ده.

## ✅ ملخص كل التعديلات اللي في المشروع ده (بالترتيب الزمني)

1. **لوحة تحكم مخصصة بالكامل** (`dashboard/`) بديلة عن أدمن Django الافتراضي
2. **إعادة تلوين المنصة بالكامل**: نظام 3 ألوان متكاملة (DarkCyan، CadetBlue،
   MediumAquamarine، DarkSeaGreen) + اسم "Hamada Ramadan" + مادة "الدراسات
   الاجتماعية" + خط Tajawal في كل مكان
3. **تصميم قسم "رحلتك نحو التفوق"** (Second section.html) بشكل الـ Stepper
   المتصل بخلفية صورة
4. **تصميم قسم الصورة والنص المتقابلين** (section 2 copy...html)
5. **إصلاح باج تداخل كورسات الإعدادي مع الثانوي** (روابط منفصلة تمامًا
   لكل مرحلة دراسية)
6. **دمج حقول التسجيل**: الاسم رباعي بدل اسمين، ورقم هاتف ولي الأمر بدل
   رقمين (مع migration آمن بينقل بيانات أي طالب مسجل بالفعل تلقائيًا)
7. **صفحة رئيسية جديدة بالكامل** (تصميم Stitch) بدل النظام القديم
8. **صفحتا تسجيل الدخول وإنشاء الحساب الجديدتين** (تصميم Stitch)، بعد
   ما لقيت وصلحت مشكلتين حرجتين: الفورم كان بيرفض أي محاولة دخول تلقائيًا،
   والتسجيل كان وهمي بالكامل ومبيبعتش أي بيانات فعلية
9. **3 صفحات جديدة بتصميم Stitch**: صفحة صفوف الثانوي (`Stages.html`)،
   صفحة صفوف الإعدادي (`phase.html`)، وصفحة تفاصيل الكورس
   (`Frontend/Test/home.html`) — الأخيرة دلوقتي بتعرض بيانات حقيقية 100%
   (اسم الكورس، السعر، المحاضرات والامتحانات لكل أسبوع)، وبتفرّق بين حالة
   الزائر غير المشترك (أزرار مقفولة) والطالب المشترك فعليًا (أزرار شغالة
   بروابط حقيقية)

## ⚠️ حاجة واحدة محتاج قرارك فيها
في صفحة تفاصيل الكورس، فيه "سعر قبل الخصم" ونسبة خصم (١,٥٠٠ جنيه / خصم ٢٠٪)
في تصميم Stitch الأصلي. النظام الحالي معندوش حقل "خصم" أو "سعر قبل الخصم"
لأي كورس حقيقي، فسيبت الرقمين دول كما هما (مثال ثابت) والتزمت بعرض السعر
الحقيقي في الرقم الرئيسي بس. لو عايز نظام خصم حقيقي، محتاجين نضيف حقل جديد
للموديل — قولّي لو عايز.

## 🚀 التركيب والتشغيل

```bash
cd "Mr. Hamada Ramadan"

# 1) انسخ الصور والخطوط والوسائط من مشروعك الحالي (خطوة يدوية إجبارية)
#    Frontend/static/images, Frontend/static/Fonts, media/

# 2) بيئة افتراضية
python -m venv venv
venv\Scripts\activate        # ويندوز

# 3) المكتبات
pip install -r requirements.txt

# 4) قاعدة البيانات (اعمل نسخة احتياطية أولًا لو عندك بيانات حقيقية بالفعل)
python manage.py migrate

# 5) حساب المعلم للوحة التحكم
python manage.py createsuperuser

# 6) تشغيل
python manage.py runserver
```

الموقع: `http://127.0.0.1:8000/`
لوحة التحكم: `http://127.0.0.1:8000/dashboard/login/`

بعد الترحيل، راجع صفحة "الطلاب" في لوحة التحكم للتأكد إن بيانات أي طالب
قديم انتقلت صح (تفاصيل في قسم دمج حقول التسجيل فوق).
